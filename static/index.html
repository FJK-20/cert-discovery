🔄 Emissão via ACME (DNS-01)

Emite ou renova um certificado de verdade via Let's Encrypt, provando que você é dono do domínio com um registro DNS temporário. O modo padrão funciona com qualquer provedor de DNS, sem credencial nenhuma — automação via API é opcional.

Configurar / atualizar token da Cloudflare

Deixe em branco se só for usar o modo automático direto. Pra delegação CNAME, informe um domínio/subdomínio que esse token controla — é onde os desafios de qualquer domínio delegado vão ser publicados.
